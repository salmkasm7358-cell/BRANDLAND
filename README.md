# BRANDLAND — متجر إلكتروني عربي

متجر Front-End متعدد الصفحات بتصميم فاخر أسود/ذهبي/وردي، مبني باستخدام HTML5 وCSS3 وJavaScript، ومتوافق مع RTL والهواتف.

## التشغيل محليًا
1. فك ضغط مجلد `BRANDLAND`.
2. افتح `index.html` في المتصفح. يفضّل استخدام إضافة Live Server في VS Code لتجربة أفضل.
3. لا يحتاج المشروع إلى تثبيت حزم أو بناء (Build).

## الصفحات
- `index.html` الرئيسية
- `categories.html` الأقسام
- `products.html` المنتجات والفلاتر والترتيب
- `product-details.html?id=w101` تفاصيل المنتج
- `cart.html` السلة
- `checkout.html` إتمام الطلب (الدفع عند الاستلام)
- `success.html` نجاح الطلب
- `wishlist.html` المفضلة
- `account.html` حسابي
- `login.html` دخول تجريبي محلي
- `track-order.html` تتبع الطلب
- `faq.html` الأسئلة الشائعة
- `search.html?q=ساعة` نتائج البحث
- `sidebar.html` روابط القائمة

## البيانات والتخصيص
- المنتجات: `js/products.js`
- الأقسام: `js/categories.js`
- التخزين المحلي: `js/storage.js`
- منطق الواجهة: `js/app.js`
- التنسيق: `css/style.css`

يمكن تعديل المنتجات من `js/products.js` مع المحافظة على الحقول: `id`, `name`, `category`, `price`, `oldPrice`, `rating`, `stock`, `badge`, `image`, `description`, `featured`, `sold`.

## التخزين والدفع
هذه نسخة ثابتة لا تحتوي على خادم أو قاعدة بيانات مشتركة. السلة والمفضلة والطلبات والحساب التجريبي تحفظ في `localStorage` على الجهاز والمتصفح الحالي فقط. لا تنتقل تلقائيًا إلى أجهزة أخرى، وقد تُحذف عند مسح بيانات المتصفح. الدفع عند الاستلام واجهة لتسجيل الطلب فقط؛ لا يوجد تكامل مع شركة شحن أو بوابة دفع.

## الصور
تستخدم صور منتجات مستضافة على Unsplash عبر روابط صور مباشرة. يلزم اتصال بالإنترنت لعرض هذه الصور. يمكن استبدال الروابط بصورك المحلية داخل بيانات `js/products.js`.

## الرفع إلى GitHub
1. أنشئ مستودعًا جديدًا باسم `BRANDLAND`.
2. ارفع محتويات المجلد (بما فيها `index.html`) إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم **Save**.
6. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## ملاحظات
- كل صفحة ملف HTML مستقل، ويعاد استخدام ملفات CSS وJavaScript المشتركة لتسهيل الصيانة.
- تسجيل الدخول تجريبي محلي وليس نظام مصادقة آمنًا.
- رقم الطلب وتتبع الطلب يعملان داخل المتصفح نفسه فقط.
